# محول فيديو تيك توك — 60FPS بجودة عالية

موقع ويب بسيط يحول الفيديو إلى **60 إطار/ثانية** مع إعدادات ترميز مناسبة لتيك توك، والمعالجة تتم **داخل المتصفح** باستخدام FFmpeg.wasm (بدون رفع الفيديو لسيرفر).

## المميزات

- تحويل الفيديو إلى 60fps (أوضاع: Blend / MCI / تكرار إطارات)
- إعداد TikTok المثالي: إطار عمودي 1080×1920، H.264، bitrate عالي، AAC 192k، `faststart`
- خيار حدة خفيفة (Sharpen)
- يعمل كصفحة ثابتة (Static) — مناسب للاستضافة المجانية

## الملفات

- `index.html` — الواجهة
- `style.css` — التنسيق
- `app.js` — منطق التحويل باستخدام ffmpeg.wasm

## التشغيل محليًا

> ملاحظة: يفضل التشغيل عبر سيرفر محلي بسيط بدل فتح الملف مباشرة.

```bash
# باستخدام Python
python3 -m http.server 8080

# أو باستخدام Node
npx serve .
```

ثم افتح: `http://localhost:8080`

## النشر على استضافة مجانية

### GitHub Pages
1. ارفع الملفات إلى مستودع GitHub.
2. من Settings → Pages اختر الفرع (`main`) والمجلد (`/root`).
3. انتظر النشر وافتح الرابط.

### Netlify / Vercel (Static)
- ارفع المجلد كما هو (بدون build).
- تأكد أن `index.html` في الجذر.

## ملاحظات مهمة

- **أول تشغيل** يحمل محرك FFmpeg.wasm (حجم تقريبي ~30MB) وهذا طبيعي.
- التحويل داخل المتصفح يعتمد على قوة جهاز المستخدم؛ المقاطع الطويلة/الكبيرة قد تكون بطيئة أو تفشل بسبب الذاكرة.
- وضع **MCI** يعطي حركة أفضل نظريًا لكنه بطيء جدًا في المتصفح — الوضع الافتراضي **Blend** هو الأنسب.
- تيك توك يعيد ضغط الفيديو بعد الرفع، لذلك الأداة تقلل فقدان الجودة لكنها لا تلغي ضغط تيك توك تمامًا.
- لأفضل نتيجة داخل تيك توك: فعّل خيار **Allow high-quality uploads** عند النشر إن كان متاحًا.

## إعدادات FFmpeg المستخدمة (تقريبًا)

- فلتر FPS: `minterpolate=fps=60:mi_mode=blend` (افتراضي)
- TikTok preset: scale/pad إلى 1080x1920 + `libx264` + `crf 18` + `12M` bitrate + `aac 192k` + `+faststart`
